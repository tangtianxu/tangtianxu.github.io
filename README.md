# 唐天旭 · 个人主页

公开网站：https://tangtianxu.github.io/

面向具身智能、机器人策略学习与模型部署岗位的个人能力和项目展示。

## 更新内容

- 首页文字、教育经历和项目入口：`index.html`
- 各项目的展示介绍：`projects/` 内对应的 HTML 文件
- 页面颜色、间距和排版：`styles.css`
- 项目照片、演示视频及展示版个人概览：`assets/`

可在 GitHub 中打开文件，点击编辑按钮修改并提交。主分支更新后，GitHub Pages 会自动发布；通常需要数分钟。

这是无需构建的静态网站，不需要 GPT、API 密钥、数据库或访客登录。
仓库包含个人简介、项目演示、数采平台真实截图，以及研究方法概览、模块结构图和实验结果。完整论文 PDF 暂不公开。

## 本地查看

可以直接打开 `index.html`，也可以用任意静态文件服务器预览整个文件夹。
